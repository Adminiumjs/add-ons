Customiser: the set-up's Fonts step draws each font's sample in that font, loading every font that has a file into the page. A font whose file is replaced is loaded again, one that failed to load is tried again, and the shop's fonts are loaded under the Customiser's own names, so a shop's Manrope never stands in for the dashboard's.
