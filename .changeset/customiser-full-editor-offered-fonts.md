Customiser: the full editor offers the base's offered fonts alone, and new words start in the base's first offered font. A words layer already set in a font the base no longer offers keeps it, listed beside the offered ones. A base that names no fonts, or none still switched on, offers the starter fonts and its own shop's, never a font another app on the install uploaded, and a design set in another app's font is refused when ordered.
