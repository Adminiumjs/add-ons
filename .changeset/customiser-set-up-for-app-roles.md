Customiser: an app's role may now be given everything the set-up page reads and writes (the settings to read; the shop's bases, pieces, areas, ready-made designs and their parts, fonts, palettes, colours and features to add, change and remove, a base never removed), so a shop's owner opens the set-up without the Customiser designer role. The set-up adds the starter fonts' files into their rows the first time somebody who may change the fonts opens it. The order-line panel names each part of the design's own layout once, and a piece's proof shows a logo set to "Make it one colour" as the laser cuts it. A link to a design version is named by its number. Holiday Calendars' picker starts on the shop's own country: the set it already took, else its browser's time zone or language. `@adminium/add-on-host/testing` no longer exports `HOST_BEHAVIOURS`, which no host reads.
