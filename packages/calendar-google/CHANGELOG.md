# @adminium/add-on-calendar-google

## 1.0.34

### Patch Changes

- 10a7b70: Google Calendar and Outlook Calendar, two new add-ons. Each person connects their own calendar from a link. Bookings go into a calendar the add-on keeps there, and the person's busy times block their slots. Only times are read, never what an event is called. Each add-on has its own page and a five-step setup guide for the business's own Google or Microsoft app.
