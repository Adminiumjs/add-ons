# Trademarks

**See [`../../TRADEMARKS.md`](../../TRADEMARKS.md).** Every mark any add-on in
this repository references is listed there, once, with the affiliation
disclaimer and the no-logo rule that bind all of them — and this add-on's own
detail lives there as a section rather than in a seventh copy of the same page.

This add-on references **no mark at all**, which is exactly why it still has a
section over there: an absent line is indistinguishable from a forgotten one.

The section is worth reading for this package in particular, because the
distinction is easy to get backwards. An invoice exists to name a company — but
every name on a rendered document is the OPERATOR'S and arrives at render time
in the subject. What the section is about is the marks the package itself could
have named in its own code and its own eight locale bundles: the paper sizes,
the font, and a payment service. None of the three is named, and each is checked
rather than asserted.
