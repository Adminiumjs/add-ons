### Patch Changes

- b3721e6: A new add-on, Live chat: a chat window on your website, answered by your team in Adminium, with automatic answers you write if you want them. Adminium serves the window, keeps every conversation and writes every message; no code of the add-on runs for a visitor. Its one Library page holds the inbox (waiting for a person, mine, all), a conversation with take over, reply, Make an enquiry, close and reopen, and Chat settings with the answers, "Try a question", the daily token limit and the chat's own status. Two roles: Chat agent and Chat settings manager. Needs Adminium 0.3.64 on a public https address.
